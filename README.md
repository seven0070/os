# PraisonAI Cursor Plugin

Teaches Cursor Agent how to build with [PraisonAI](https://github.com/MervinPraison/PraisonAI): agents, multi-agent teams, AgentFlow, MCP tools, memory, RAG, YAML, and CLI.

## Install into Cursor (user scope)

1. Open **Customize** in the Cursor sidebar
2. Add / install this repository as a plugin or remote skill source
3. Set scope to **User** so it applies across all projects

### Local plugin path

Cursor also loads plugins from `~/.cursor/plugins/local/praisonai`.

### Skill-only paths

- User (global): `~/.cursor/skills/praisonai/`
- Project: `.cursor/skills/praisonai/`

Invoke with `/praisonai` or let Agent pick it up when PraisonAI work comes up.
